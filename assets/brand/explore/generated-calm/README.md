# Calm Alopex DB mascot exploration

Eight separate illustrations generated with the built-in `image_gen` tool, using the same fox in a quieter editorial register. Generated PNGs were copied unchanged; no Pillow, SVG, code-drawn artwork, compositing, cropping or resampling was used. All calls used `transparent_background: false`.

The final **b10 portrait** is the shared identity/style reference for the other seven scenes. It was established by revising an initial calm portrait that still had excessive shading, fur detail and neck ruff. Both portrait prompts are included below; the initial attempt is not a deliverable.

Compared with the matching scenes in [the earlier set](../generated/README.md), this register has smaller dark eyes, fewer fur masses, reduced neck ruff, much less contour, muted accents and more poised full-body proportions. The tail, white coat, blue inner ears and tapered muzzle keep the relationship recognizable. Side views have the strongest species read; compact curled views still allow some cat ambiguity. The quieter version is a better direction for documentation and technical slides because its shapes demand less attention alongside text and diagrams. It is still friendly. My first owner-review picks are **b10 portrait, b04 blizzard, b11 summit and b13 trail**.

Limitations: although the prompts demand solid flat fills, the generated files retain slight tonal softness or texture in some broad regions and occasional nose shine. This is a substantial register change, not a perfect production-vector execution of every constraint. Ears remain somewhat larger than specified; body/tail proportions vary by pose, especially in the walking banner. A literal production vector version would still need refinement.

Dimensions: seven squares are **1254 × 1254**. The trail is **1672 × 941**, a native wide output very close to, but not mathematically exact, 16:9; it has not been cropped. No files in `../generated/` were changed.
